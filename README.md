# Multi-Page Navigation Website

This project is a basic multi-page website created using HTML and CSS. The website consists of five interconnected pages: Home, About Us, Project, Achievements, and Contact Us. The Home page serves as the main entry point and provides navigation to all other pages through a responsive menu.

## Features

* Multi-page website structure
* Home page as the main landing page
* Navigation menu linking all pages
* Hover effects on menu items
* Unique gradient background on each page
* Clean and beginner-friendly design

## Technologies Used

* HTML
* CSS

  

## Pages Included

### Home Page

The main page of the website that provides navigation links to all other sections. It uses a red-to-orange gradient background.

### About Us

Contains the About Us section and uses a sky blue to purple gradient background.

### Project

Displays project-related content with a sky blue to navy gradient background.

### Achievements

Represents the achievements section with a bisque-to-brown gradient background.

### Contact Us

Contains contact-related content and uses a green gradient background.

## How to Run

1. Download or clone the repository.
2. Keep all HTML files in the same folder.
3. Open `home.html` in any web browser.
4. Use the navigation menu to move between pages.
